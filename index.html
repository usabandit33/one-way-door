Scratching in the attic? Ask if they use a one-way door before anyone sets a trap.

Chicago homeowners keep paying for a trap visit that misses babies, then a second bill to patch the soffit the raccoon used. A national form will not write that sequence. Ask it yourself.

  • Ask if they install a one-way door so the animal leaves and cannot climb back in.
  • Ask how they check for young before the last hole is sealed.
  • Ask who repairs the vent, soffit, or chimney — same crew or a separate carpenter.
  • Ask whether Illinois law lets them relocate a raccoon off your lot, or only release on site.
  • Ask for the Nuisance Wildlife Control Operator number you can look up.
  • Prefer a shop that publishes a phone on its own site, not only a Maps pin.
