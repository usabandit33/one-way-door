Scratching in the attic at night. Ask about a one-way door before anyone sets a trap.

When raccoons or squirrels get into a Chicago attic, a trap-only visit can miss babies in the insulation and leave the soffit open for the next animal. Use this checklist before you book.

  • Ask if they install a one-way door so the animal leaves and cannot climb back in.
  • Ask how they check for young before the last hole is sealed.
  • Ask who repairs the vent, soffit, or chimney — same crew or a separate carpenter — and when.
  • Ask what Illinois allows for a raccoon on your lot (often release on-site only).
  • Ask for the Nuisance Wildlife Control Operator number you can look up.
  • Call a shop that publishes a phone on its own website and run through this list.
